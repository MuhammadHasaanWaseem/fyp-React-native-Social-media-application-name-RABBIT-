# Rabbit - Social Media App

## 🚀 Starter Features

### 🏁 Splash and Onboarding Screen
- Welcomes users and provides a brief introduction to the app.

### 🔐 Authentication with Supabase
- Secure login and signup features.
- Allows users to create unique usernames during registration.

## 📢 Posting & Content

### 📝 Post Screen
- Users can upload audio, video, images, text, and GIFs.
- Tagging system: mention users with @username and use hashtags like #topic.

### 🏷️ Post Types
- **Spoiler Blur**: Posts marked as spoilers appear blurred until clicked.
- **Premier Post**: Schedule posts to be released to followers at a certain time.
- **Time Capsule**: Set posts to unlock after a specific duration (locked media).

## 📣 User Interaction and Engagement

### 🏡 Home Feed
- View posts, like, comment, and share.
- Support for sharing posts externally.

### 🔎 Search and Discovery
- Search for users, follow/unfollow them, and view their profiles.

### 🏠 Profile Screen
- Three privacy modes: Public, Private, Capsule (time-locked posts).
- Share your profile externally.
- Edit profile details.

### 🔔 Notifications
- Real-time notifications for likes, comments, and mentions.

## 💬 Messaging and AI Integration

### 💌 Messaging
- Real-time chat feature available with global users.

### 🤖 AI Integration
- DeepSeek Llama R1 chatbot integrated via OpenRouter API.

## 🛡️ Privacy and Contextual Features

### 🔏 Context-Based Privacy
- Users can customize privacy settings based on context (e.g., specific audiences for certain posts).

---

## 🛠 Technologies Used

- **React Native Expo Router**
- **Prisma**
- **Supabase**
- **Gluestack Library**
- **TanStack Query**
- **Twilio Verify** for user authentication
